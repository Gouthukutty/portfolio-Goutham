GOUTHAM D — SIMPLE RESUME-STYLE PORTFOLIO

The portfolio intentionally uses a clean, minimal resume-style design with neutral colors.

PROFILE PHOTO:
Replace the .photo-placeholder section in index.html with:
<img src="profile.jpg" alt="Goutham D">

Then place your profile.jpg in the same folder.

RUN:
Open index.html in a browser.

PUBLISH:
Upload the files to GitHub and enable GitHub Pages, or deploy the folder with Vercel/Netlify.
